# IoT and Machine Learning Based Landslide Early Warning System

## Overview

This project uses IoT sensors and machine learning techniques to monitor environmental conditions and provide early warning alerts for landslide risks.

## Components Used

- ESP32
- Soil Moisture Sensor
- Rain Sensor
- DHT11
- MPU6050
- LEDs and Buzzer

## Workflow

Sensors → ESP32 → ThingSpeak → Machine Learning Model → Alert System

## Features

- Real-time monitoring
- Cloud integration using ThingSpeak
- Landslide risk prediction
- Alert generation using LEDs and buzzer

## Machine Learning Model

Algorithm Used: Random Forest Classifier

Risk Classes:
- Low Risk
- Medium Risk
- High Risk

## Results

- Accuracy: 94%
- Precision: 94.27%
- Recall: 94%
- F1 Score: 93.6%
